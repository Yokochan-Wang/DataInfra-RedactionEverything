# 改动记录 —— 文本模型本地 / 远端可切换（2026-09-21）

目标：把"文本 NER 用哪个模型"从 .env 提升为**可运行时切换**的配置，并让主页「本地服务」
显示的名称跟随选定的模型；为后续换成本地小模型留出安全试错空间。

## 一、后端

### 1. `backend/app/core/ner_runtime.py`（重写）

- 配置结构从单字段（`backend` + `llamacpp_base_url`）升级为 **schema 2**：
  `active`（local / remote）+ `local` / `remote` 两份 `TextModelProfile`
  （`base_url` / `api_key` / `model_name` / `display_name`）。
- 新增 `load_ner_runtime()`（**生效**配置，旧格式返回 None）、
  `load_ner_runtime_for_ui()`（设置页展示用，旧格式会自动迁移）、
  `save_ner_runtime()`、`delete_ner_runtime()`、`TextModelProfile.effective_name()`。
- `model_validator(mode="before")` 兼容旧请求体（`test_role_matrix.py` 用的
  `{"backend":"llamacpp","llamacpp_base_url":...}` 仍返回 200）。
- **旧格式文件保持不生效**：它历史上一直被 .env 覆盖（`get_has_chat_base_url` 的
  解析顺序里它是最后一级兜底），若升级后突然抢到最高优先级，会把现网从远端 4090
  静默切到一个没在跑的 `127.0.0.1:8080`。因此只有 `schema=2` 的文件才生效。
- 读文件不做缓存：文件很小（< 1 KB），每次请求读一次换来"保存即生效无延迟"，
  避免 TTL 缓存导致主页名字滞后一秒。

### 2. `backend/app/core/config.py`

新增 / 修改的解析函数（运行时配置一律优先于 .env）：

| 函数 | 变化 |
|---|---|
| `_runtime_text_profile()` | 新增：取当前生效的 profile |
| `get_effective_text_runtime()` | 新增：返回 `"remote"` / `"local"` |
| `is_remote_text_runtime()` | 新增：下游按远端 / 本地分流的唯一判定 |
| `get_has_chat_base_url()` | **运行时地址最优先**，其次才是原来的 external / vllm / HAS_BASE_URL / llamacpp 分支 |
| `get_has_text_model_name()` | 新增：运行时 `model_name` 优先；运行时配置存在时**不再回落 .env**（本地服务上发远端模型名会 404） |
| `get_has_text_headers()` | 运行时 Key 优先；运行时**没填 Key 就不回落到 .env 的远端 Key**，避免把 4090 的 Key 发给本机 llama-server |
| `configured_text_display_name()` | 新增：设置页显式选定的显示名（无运行时配置时为 None） |
| `get_has_display_name()` | 显示名 / 模型名最优先 → 再 HAS_NER_DISPLAY_NAME → HAS_TEXT_MODEL_NAME → 默认值 |

### 3. `backend/app/services/has_client.py`

- `_call_model()` 的 `payload["model"]` 改用 `get_has_text_model_name()`；
- `reasoning_effort="none"` 的判定改用 `is_remote_text_runtime()`。
  （原来读 `settings.HAS_TEXT_MODEL_NAME` / `settings.HAS_TEXT_RUNTIME`，而 `get_settings()`
  带 `@lru_cache`，运行时改配置根本不生效。）

### 4. `backend/app/core/gpu_inference_gate.py`

- 全局推理闸门的"远端旁路"判定：`settings.HAS_TEXT_RUNTIME == "external"` →
  `is_remote_text_runtime()`。切到本地模型时闸门自动重新生效（单卡安全）。

### 5. `backend/app/services/closed_loop_recognition_20260902.py`

- `_runtime_adaptive_max_rounds()` 同样改用 `is_remote_text_runtime()`：
  远端 1 轮（省网络往返），本地 3 轮。

### 6. `backend/app/core/health_checks.py`

- `_has_text_runtime_detail()`：远端分支改用 `is_remote_text_runtime()`，
  `model` / `base_url` 取生效值；本地分支在有运行时配置时不再走 vllm 判定。
- `check_has_ner_health()`：**设置页显式选定的名字优先于服务端自报的名字**——
  这正是需求里"模型名填 aaa，主页就显示 aaa"的落点（原来 strict 探测会用
  `/v1/models` 返回的名字覆盖显示名）。

### 7. `backend/app/api/ner_backend.py`（重写）

- GET 返回两份配置 + active（Key 脱敏为 `__REDACTED__`）；
- PUT 保存两份配置并把 `active` 设为生效项；收到 `__REDACTED__` 时保留服务端原 Key；
  地址留空时保留已知地址（避免误清空导致链路指向空地址）；
- POST `/test` 用被测页签的地址与 Key 探测，成功时把服务端自报的模型名一起回显；
- DELETE 删除覆盖，恢复 .env；
- 保留原 SSRF 白名单校验与 `super_admin` 网关。
